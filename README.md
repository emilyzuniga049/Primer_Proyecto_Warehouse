Proyecto #1 de Minería de Datos (UTN, 3C2026). Implementación de un data warehouse con proceso ETL en Azure Data Factory.

## Tecnologías
- Azure Data Factory (ETL)
- Azure SQL Database (base fuente y DW)
- Excel (tablas dinámicas conectadas al DW)

## Estructura
- `docs/` – documentación del proyecto y registro de sprints
- `sql/` – scripts de análisis de calidad y creación del DW
- `adf/` – pipelines de Azure Data Factory
- `excel/` – reportes y tablas dinámicas

- Servidor SQL: `sql-invacom-john`
